# Modernize documentation generation

Status: complete (dependency cleanup and generation stage)

## Objective

Keep CGView's customized Jaguar appearance while removing unused documentation
dependencies and making API generation reliable and verifiable.

## Scope

- Remove the unused Dash template and docset configuration.
- Retire Jaguar's Grunt, demo, and obsolete LESS build setup.
- Preserve the Jaguar templates, CSS, attribution, and CommonJS package boundary.
- Replace TaffyDB with JSDoc's Salty implementation and remove the publisher's
  direct Underscore dependency.
- Update the active documentation dependencies and their resolved dependencies.
- Generate and validate documentation during local development and CI.
- Add browser cleanup and dark mode in a subsequent stage unless requested for
  this first implementation.

## Acceptance criteria

- One root lockfile controls documentation dependency installation.
- No Dash, Grunt, or TaffyDB dependency remains in the active project manifests
  or lockfile.
- The existing source generates API documentation successfully.
- Existing API page names and anchors are compared with a fresh baseline build.
- Documentation checks verify generated navigation, source links, required local
  assets, search, and mobile navigation. Existing prose links are recorded separately.
- The Pages workflow generates documentation before uploading the site.
- Existing library tests show no new failures after dependency changes.
- No commits or pushes are made.
