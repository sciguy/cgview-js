# Modernize documentation browser assets and theme

Status: complete

## Objective

Preserve the customized Jaguar layout while removing obsolete browser libraries
and adding a shared light, dark, and system preference to the documentation site.

## Scope

- Replace jQuery navigation with native DOM code and literal search.
- Remove unused browser libraries, icon fonts, and obsolete template integrations.
- Share current Bootstrap and Prism assets, generated from root dependencies.
- Keep existing API URLs and source line anchors.
- Use shared CSS variables for site and API colors, with a persistent theme choice.
- Extend documentation browser checks to cover search, themes, and shared pages.

## Acceptance criteria

- Search supports typing, pasting, punctuation, and clearing all member filters.
- API sections and mobile navigation work with the keyboard.
- Light mode preserves the layout; dark mode covers tables, code, and navigation.
- Theme choice persists across API, docs, tutorials, examples, and JSON pages.
- System mode responds to OS changes; blocked storage does not break navigation.
- Bootstrap and Prism assets and licenses are reproducible from the root lockfile.
- Documentation builds and browser checks pass without new browser errors.
- No library source changes or pushes.
