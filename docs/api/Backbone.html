Class: Backbone

Backbone

The CGView Backbone represents the sequence of the map. When zoomed in far enough the sequence will be shown on the backbone. If contigs are present, they will be represented as arcs or arrows on the backbone.

Attributes

Attribute Type Description
thickness Number Thickness of backbone [Default: 5]
color String A string describing the main backbone color [Default: 'grey']. See Color for details.
colorAlternate String A string describing the alternate color used for contigs [Default: 'rgb(200,200,200)']. See Color for details.
decoration String How the bakcbone should be drawn. Choices: 'arc', 'arrow' [Default: arc for single contig, arrow for muliple contigs]
showShading Boolean Override Settings#showShading for the backbone. When set, this value is used instead of the global setting. [Default: undefined]
showBorder Boolean Override Settings#showBorder for the backbone. When set, this value is used instead of the global setting. [Default: undefined]
visible Boolean Backbone is visible [Default: true]
meta Object Meta data
