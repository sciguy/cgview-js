Class: CGArray

CGArray

CGArray is essentially an array for holding CGV Objects. Any method that works on an Array will also work on a CGArray.

If a single array is provided it will be converted to an CGArray. If mulitple elements are provided, they will be added to the new CGArray.

Examples

const a1 = new CGArray(1, 2, 3);
=> CGArray [1,2,3]

const a2 = new CGArray([1,2,3])
=> CGArray [1,2,3]
