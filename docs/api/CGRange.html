Class: CGRange

CGRange

A CGRange contains a start and stop position (in base pair) on a sequence contig. Ranges are always in a clockwise direction. A stop before the start wraps within the owning contig, independently of its topology or the map format.

Ranges and Map Coordinates

Range start and stop positions are in relation to the contig the range is on. To get the positions in relation to the entire map, use mapStart and mapStop.
