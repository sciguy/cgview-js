Help • Log
A log is only shown when using 'Open a file...'
  • The Test Page is a convienent place to experiment with CGView maps and features.
  • In addition to the built-in maps, you can upload your own CGView JSON file or a sequence file (e.g. GenBank, EMBL, FASTA). Sequence files are converted to CGView JSON with CGParse.js. Uploaded files are parsed using the same config as all the examples.
  • The viewer object for this map can be accessed in your browser JavaScript console as cgv.
  • Performance tests render the current map at different zoom levels and records both fast and full draw times. This can help evaluate the performance of new features. For meaningful comparisons, tests should be run under the same conditions (e.g. computer, browser, map size).
  • Clicking Open in Proksee sends the CGView JSON to Proksee to start a new project.
