It also includes an example of a complete HTML file using jsDelivr for installation. ### Responsive Map Size ```js // Tutorials and examples call a resize function after drawing the map, // allowing it to adjust automatically when the window or layout changes. function autoResizeMyViewer() { const setHeight = 500; const mainPadding = 20 * 2; function myResize() { const main = document.getElementsByTagName('main')[0]; const mainWidth = main.clientWidth - mainPadding; const height = Math.min(mainWidth, setHeight); cgv.resize(mainWidth, height); } window.onresize = myResize; window.onload = function () { setTimeout( () => { myResize(); }, 100); } } ```
